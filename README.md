# OS Web

A browser-based recreation of a desktop operating system experience built using HTML, CSS and JS.

### [Click Here to Try Live Demo](https://rajankckc.github.io/OSWeb)

# Quick Start

To try out right now, simply clcik the [Live Demo Link](https://rajankckc.github.io/OSWeb) above.

## Features

* **Interactive Desktop environment** - A clean workspace with applications.
* **Draggable Windows** - Native desktop feel with custom grab-and-drag window headers.
* **Functional Noyes App** - Open and type your notes directly inside notes app.

# How to Run Locally

## Requirment

* Any web browser (Chrome, Firefox, Edge, Safari).
* A local server enviroment (Like VS Code's Live Server Extension).

## Setup Instructions

1. **Clone the Repository**:

```Bash
git clone https://github.com/RajanKCKC/OSWeb.git
cd OSWeb
```

2. **Run it locally**:

* Right-Click `index.html` and open it with any web browser.
* In VS Code, right-click `index.html` and click **Open with Live Server**.

3. **Open the browser**:

Go to `http://localhost:8080` to see your OS in action!
